# DataWidget（回線残量ウィジェット）

docomo / ahamo など日本の主要キャリア・MVNOの「残りデータ量」を、キャリア公式アプリを開かずホーム画面ウィジェットで確認できるAndroidアプリ。

- パッケージ名: `com.akun.docomodata`
- バージョン: v1.00
- 対応: Android 5.0 (API21) 以上
- 提供形態: APK直接配布（Google Play非公開）

## 特徴

- **プロファイル制**: キャリア回線ごとに「プロファイル」を作成して管理。複数回線を同時に登録し、ホーム画面の別々のウィジェットにそれぞれ紐付けられる（docomoとahamoを両方1画面に並べる、といった使い方が可能）
- **ワンタップ更新**: ウィジェットをタップするとその場で「更新中…」表示に切り替わり、裏で該当プロファイルだけを再取得
- **しきい値通知**: プロファイルごとに「◯GB/MB を下回ったら通知」を設定可能。閾値を上回るまで再通知はしない
- **定時サマリー通知**: 毎日決まった時刻に、登録している全プロファイルの残量をまとめて1件の通知で確認できる
- **自動更新間隔のカスタマイズ**: バックグラウンドでの自動取得頻度を15分／30分／60分／120分から選択可能（短くするほどバッテリー消費は増える）
- **テーマ**: 6種類の配色テーマに加え、背景色・文字色・アクセント色を個別に指定できるカスタムカラーにも対応。新規プロファイル作成時のデフォルトテーマも設定画面から変更可能
- **設定のエクスポート/インポート**: 全プロファイル設定をJSONとして書き出し・読み込みでき、機種変更時の引き継ぎにも使える
- **アプリロック**: 指紋認証・顔認証・端末の画面ロック（PIN/パターン/パスワード）でアプリの起動を保護。対応していない端末ではアプリ内パスワード入力に自動でフォールバックする
- **日本語/English切替**: アプリ内表示言語を設定画面からいつでも切り替え可能
- **可変サイズ対応ウィジェット**: 1×1相当の最小サイズから横長サイズまで、どのサイズに変更してもレイアウトと文字サイズが自動調整される
- **アップデート通知**: 新しいバージョンがGitHubで公開されると、1日1回のチェックで通知が届く

## 使い方

1. アプリを起動し、「＋新規プロファイル」をタップ
2. キャリアをプリセットから選択（または「自由入力」でログインURL・マイページURLを直接入力）
3. 表示された内蔵ブラウザでキャリアのマイページにログイン
4. 残量が表示されているページを開いた状態で「保存」
5. ホーム画面を長押し→ウィジェット→「回線残量ウィジェット」を選び配置
6. 配置時に、どのプロファイルを表示するかウィジェットごとに選択

以降は自動更新間隔ごとにバックグラウンドで残量が更新される。手動で最新化したい場合はウィジェットを直接タップすればよい。

## 動作の仕組み

キャリアの残量データを取得する公式APIは公開されていないため、本アプリは内蔵WebViewでキャリアのマイページに直接ログインし、そのセッション（Cookie）を保持したままバックグラウンドの別WebViewでページを再読み込みし、表示されたテキストから正規表現で残量の数値を抜き出している。

- ログインID・パスワードはアプリ・開発者のいずれにも送信・保存されない（すべて端末内のWebViewで完結する処理）
- 保存されるのはCookieセッションと、抽出した残量の数値・更新時刻のみ
- キャリア側がマイページの構造（HTML）を変更すると、正規表現が一致せず残量が取得できなくなる場合がある。その場合はプロファイル編集画面から正規表現パターンを調整することで対応できる

## 必要な権限

| 権限 | 用途 |
|---|---|
| INTERNET | キャリアマイページへのアクセス |
| ACCESS_NETWORK_STATE | 通信状態の確認 |
| RECEIVE_BOOT_COMPLETED | 再起動後の定期更新再開 |
| FOREGROUND_SERVICE | データ取得中のフォアグラウンド処理 |
| WAKE_LOCK | 取得処理中のスリープ防止 |
| POST_NOTIFICATIONS | しきい値/定時サマリー/アップデート通知の表示（Android 13+） |
| REQUEST_IGNORE_BATTERY_OPTIMIZATIONS | バックグラウンド更新を安定させるための最適化除外リクエスト |
| USE_BIOMETRIC | アプリロックでの指紋・顔認証の利用 |

## インストール方法

Google Play非公開のため、APKを直接インストールする。

### 初回インストール

1. [Releases](https://github.com/haizarakun/DataWidget/releases) から最新の `DataWidget.apk` をダウンロード
2. 端末の設定で「提供元不明のアプリ」のインストールを許可
3. ダウンロードしたAPKをタップしてインストール
4. ホーム画面を長押し→ウィジェット→「回線残量ウィジェット」を配置
5. 初回はプロファイル作成（キャリアのログインURL/マイページURLを設定）が必要

### アップデート

固定の署名鍵で継続配布しているため、[Releases](https://github.com/haizarakun/DataWidget/releases) から新しいAPKをダウンロードしてそのままインストールするだけでよい。アンインストールは不要で、プロファイル設定もそのまま引き継がれる。

> それより前の古いビルド（署名鍵が異なるバージョン）を使っている場合のみ、一度アンインストールしてから最新版を入れ直す必要があります。
